# 二维码生成器 - Brave/Chrome 浏览器扩展

一个轻量级的 Brave/Chrome 浏览器扩展，支持右键或点击图标快速生成二维码。内容可编辑，任意文字都能生成，不要求必须是网址。

## 功能特性

- 🖱️ **右键菜单**：在页面、选中文字、链接、图片上右键生成二维码
- 🔘 **工具栏图标**：点击图标即可打开生成器；当前标签页没有网址（新标签页、`chrome://` 页面等）时也能打开
- ✏️ **可编辑内容**：内容区域是输入框，可直接修改、粘贴任意文字后生成二维码
- ⚡ **即时生成**：输入时自动更新二维码，也可点击「生成二维码」
- 🔤 **地址栏快捷入口**：在地址栏输入 `qr` 再按空格，粘贴任意内容后回车（或点击提示），即可生成二维码，不必是网址
- 🪟 **模态框显示**：在普通网页上以模态框展示二维码，支持动画效果
- 📋 **复制内容**：一键复制当前输入框中的文本
- 💾 **下载二维码**：支持将二维码保存为 PNG 图片
- ⌨️ **快捷键支持**：按 ESC 键快速关闭
- 🎨 **精美 UI**：渐变紫色主题，现代化设计风格
- 🔒 **纯本地生成**：所有二维码在本地生成，不上传任何数据

## 安装方法

### 方法一：开发者模式加载（推荐）

1. 打开 Brave/Chrome 浏览器，在地址栏输入 `chrome://extensions/`（Brave 为 `brave://extensions/`）并回车
2. 开启右上角的 **"开发者模式"** 开关
3. 点击 **"加载已解压的扩展程序"** 按钮
4. 选择本扩展所在的文件夹（包含 manifest.json 的目录）
5. 安装完成！扩展图标会出现在浏览器工具栏

### 方法二：从 Release 安装

在 [GitHub Releases](https://github.com/corle-bell/QR_Code_Creator/releases) 页面下载 zip 后解压，再用上面的「加载已解压的扩展程序」安装。

推送 `v1.1.0` 这种与 `manifest.json` 版本号一致的 tag 时，GitHub Actions 会自动打包 zip 并发布到 Release。

## 使用方法

### 方式一：点击扩展图标

点击浏览器工具栏上的扩展图标，即可打开二维码生成器：

- 若当前页面有普通网址（http/https），会自动填入输入框并生成二维码
- 若地址栏为空，或当前是新标签页、`chrome://` 等无法注入脚本的页面，仍会打开生成器，输入框为空，可直接输入或粘贴内容
- 在输入框中修改或粘贴任意文字（不必是网址），二维码会自动更新

### 方式二：地址栏关键字

1. 在地址栏输入 `qr`，然后按空格
2. 粘贴或输入任意内容（普通文字、口令、链接都可以）
3. 按回车，或点击下拉提示

插件会打开生成窗口并显示对应二维码。

### 方式三：右键菜单

1. **生成当前页面二维码**：在页面空白处右键 → 选择「生成当前页面二维码」
2. **生成选中文字二维码**：选中一段文字 → 右键 → 选择「生成选中文字二维码」
3. **生成链接二维码**：在链接上右键 → 选择「生成此链接二维码」
4. **生成图片地址二维码**：在图片上右键 → 选择「生成此图片地址二维码」

在普通网页上，二维码会以页面内模态框显示。如果当前页面不允许注入脚本（例如新标签页、浏览器设置页），会改为弹出独立的生成窗口，内容同样可以继续编辑。

## 模态框 / 弹窗操作

- **编辑内容**：在「内容」输入框中输入或粘贴文字，二维码会即时更新；也可点击「生成二维码」
- **关闭**：点击右上角 × 按钮、点击遮罩层（页面内模态框）、或按 ESC 键
- **复制内容**：点击「复制内容」按钮，将当前输入框中的文本复制到剪贴板
- **下载二维码**：点击「下载二维码」按钮，保存为 PNG 图片

## 技术说明

- 使用 **Manifest V3** 标准，兼容 Chrome/Edge/Brave 等 Chromium 内核浏览器
- QR 码生成基于开源库 qrcode-generator（Kazuhiko Arase）
- 纯前端实现，无需网络请求，保护隐私
- 支持中文等 UTF-8 字符
- 按需注入内容脚本（`activeTab` + `scripting`），不预加载到所有页面
- 当前版本：`1.1.0`

## 常见问题

**Q: 为什么在新标签页或地址栏为空时点图标打不开？**
A: 旧版本会在当前标签页没有网址，或无法向页面注入脚本时直接退出。1.1.0 起点击图标会打开插件自己的弹窗，空地址也可以使用。

**Q: 为什么右键菜单不显示？**
A: 请确认扩展已正确加载。右键菜单由后台注册，一般安装后即可使用；若刚安装，可刷新页面后再试。

**Q: 二维码能生成多长的内容？**
A: 最多约 2953 字节（大约 900 多个汉字，或近 3000 个英文字符）。超出时会在输入框下方和二维码区域给出提示，不会生成无效图片。

**Q: 会收集我的数据吗？**
A: 不会。所有二维码都在本地生成，不会上传任何数据到服务器。

**Q: 我把一段文字贴到了地址栏，但还没按回车，插件能读到吗？**
A: 浏览器不允许扩展直接读取地址栏里尚未跳转的内容。请改用这两种方式：直接点击图标，在弹窗输入框里粘贴；或在地址栏先输入 `qr` 再空格，然后粘贴内容并回车。
